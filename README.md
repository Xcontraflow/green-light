# Green Light

一个轻量的工时记录小工具：**打开就开始计时**，今日累计工时达到目标后红灯变绿灯，并提供周/月统计。

- 单文件 Python 脚本，仅依赖标准库（含 Tkinter / winreg）
- 程序本体 < 15 KB，数据文件 JSON 文本
- 原生 Windows 注册表实现开机自启动

## 运行环境

- Windows 10 / 11
- Python 3.8 +（Microsoft Store 或 [python.org](https://www.python.org/) 安装均可）

## 启动

双击 `start.bat`，或在终端运行：

```
pythonw green_light.py
```

`pythonw` 启动不会弹出黑色控制台窗口。

## 功能

| 区域 | 说明 |
| --- | --- |
| 圆形指示灯 | 今日工时 < 目标 → 红灯；≥ 目标 → 绿灯 |
| 本次会话 | 实时显示本次打开后的连续时长 |
| 今日进度条 | `今日累计 / 目标` 与百分比 |
| 本周 | 最近 7 天逐日柱状图 + 总计 / 日均 |
| 本月 | 总工时 / 工作天数 / 日均 / 达标天数 / 最长一天 |
| 设置 | 调整每日目标分钟数；勾选开机自启动 |

每 30 秒自动写入磁盘，关机或意外退出后下次启动会把上一段会话补回来。

## 数据

| 文件 | 内容 |
| --- | --- |
| `data.json` | 历史会话记录（start / end / duration） |
| `config.json` | 目标工时、自启动状态 |

数据完全本地存储。

## 开机自启动

在「设置」页勾选 **开机自启动**，会向以下注册表项写入 `GreenLight` 启动命令：

```
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
```

取消勾选自动移除。如果之后**移动或重命名了文件夹**，请重新勾选一次以更新路径。

## 卸载

1. 在「设置」中关闭自启动
2. 删除整个文件夹即可
